Aplicatie mobila de investitii – Managementul portofoliilor si al dividendelor
Descriere si scop
Aplicatie mobila Android pentru gestionarea portofoliilor de investitii si monitorizarea dividendelor. Scopul aplicatiei este simplificarea administrarii investitiilor si reducerea timpului necesar pentru analiza acestora.
Utilizatorul va putea introduce propriul portofoliu de investitii, va putea urmari dividendele incasate si cele estimate pentru viitor, precum si randamentul fiecarei actiuni detinute.
Aplicatia va permite si compararea companiilor pe baza unor indicatori financiari, precum capitalizarea bursiera (Market Cap), profitul si veniturile. De asemenea, va include un calculator pentru estimarea randamentului unei investitii viitoare si a dividendelor potentiale obtinute prin investirea unei anumite sume intr-o companie.
Tehnologii
- Android Studio
- Kotlin
- Jetpack Compose
Functionalitati principale
- Gestionarea portofoliului personal de investitii.
- Evidenta tranzactiilor si a actiunilor detinute.
- Monitorizarea dividendelor incasate si estimarea celor viitoare.
- Calcularea randamentului fiecarei actiuni si al intregului portofoliu.
- Compararea companiilor pe baza indicatorilor financiari.
- Vizualizarea evolutiei actiunilor si a portofoliului prin grafice.
- Calculator pentru simularea investitiilor si estimarea dividendelor potentiale.
